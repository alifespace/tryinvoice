- **真实门禁发现**：
  - Render Docker Command 不可靠解释 `&&`，导致迁移进程退出后 seed/Uvicorn 未执行；当前环境通过分别执行迁移、seed，再恢复单一 Uvicorn 命令完成对账，但该手工过程不能作为可复现部署方案。

- **安全处置**：调试期间曾出现凭证可能进入浏览器辅助信息的风险，项目所有者已完成数据库密码轮换并重新部署；本文不记录任何凭证或连接串。
- **结论**：健康检查、鉴权拒绝、迁移与 seed 门禁通过；M4.1 仍需完成 `M4.1-fix-deployment-bootstrap` 与 `M4.1-fix-supabase-jwks-auth`，并补齐真实测试账号鉴权和合成数据最小 API 链路后才能最终验收。
