# M4.5-ios-capture-import-and-ocr：文档扫描、相册/PDF 导入与端侧 OCR

- **目标**：实现 VisionKit 连拍扫描、相册多选、PDF 导入与 Vision 端侧离线 OCR，并接入 M4.4 的本地文件和上传队列。
- **前置依赖**：`M4.4-ios-offline-store-and-upload-queue`。
- **范围与约束**：
  - 集成 `VNDocumentCameraViewController`、`PhotosPicker` 与 `UIDocumentPickerViewController`，统一转换为不可变本地文档记录。
  - 使用 `VNRecognizeTextRequest` `.accurate` 模式输出文本行、置信度和坐标框，并通过 confirm 契约上传 `client_ocr_json`。
  - 图片/PDF 类型、文件大小、重复内容和导入失败使用确定性校验；禁止使用 LLM 替代端侧 OCR 或文件验证。
  - 模拟器测试使用合成且无敏感信息的图片/PDF 夹具；真实相机、相册授权和五张连拍作为真机人工门禁。
  - 本 Task 不实现交易复核、模板编辑或导出分享。
  - 预估总改动量约 1,500 行（功能 1,100 行、测试 400 行），不超过 2,000 行；新增测试低于 450 行。
- **验收标准**：
  - 模拟器导入 5 张合成小票和 1 个 PDF，均保存到 RawVault、生成 OCR 结构并进入上传队列。
  - 权限拒绝、取消选择、损坏 PDF、超限文件和 OCR 失败均有可恢复反馈，不产生半成品记录。
  - 经授权在真机完成五张连续扫描、裁边和本地保存，原件与 OCR 结果可追溯。
