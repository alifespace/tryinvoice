# M4.2-ios-project-scaffold-and-ci：SwiftUI 工程骨架与真实云端编译

- **目标**：使用 XcodeGen 创建 iOS 17+ SwiftUI 工程、共享 Scheme、基础导航和测试 Target，并让现有 GitHub Actions 从工具链探针升级为真实构建与模拟器测试。
- **前置依赖**：`M3.3-ios-cloud-ci-foundation`。
- **范围与约束**：
  - 创建 `ios/project.yml`、最小 App Target、Unit Test Target、UI Test Target，以及 `TryInvoice` 共享 Scheme。
  - 建立 App 壳层、根导航、统一错误展示和 Debug/Test 配置注入边界；真实 URL 与凭证不得硬编码。
  - 更新 `ios/README.md`，记录 M3.3 真实 CI 已通过及当前工程生成方式，移除已经失效的“首次 push 待授权”说明。
  - 本 Task 不实现登录、网络业务、SwiftData、文件上传或业务页面；不配置签名、Provisioning Profile、TestFlight。
  - 预估总改动量约 1,000 行（功能与工程配置 650 行、测试 350 行），不超过 2,000 行；新增测试低于 450 行。
- **验收标准**：
  - XcodeGen 能从零生成工程，Scheme 可被 `xcodebuild -list` 发现。
  - GitHub Actions 在 iPhone 16 / iOS 18.5 上实际通过 `build-for-testing` 与 `test-without-building`。
  - `.xcresult` 与日志仅在失败时用于诊断，不含凭证或用户数据；构建不依赖本机完整 Xcode。
