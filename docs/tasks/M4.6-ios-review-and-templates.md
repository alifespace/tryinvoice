# M4.6-ios-review-and-templates：交易复核、异常提示与模板管理

- **目标**：实现三级分组交易列表、异常告警、关联凭证查看、人工修订，以及默认模板复制和自定义编辑。
- **前置依赖**：`M2.5-transaction-review-api`、`M4.5-ios-capture-import-and-ocr`。
- **范围与约束**：
  - 批次详情展示 `missing_alerts`、待确认计数与三级分组；金额显示只消费服务端结果，客户端不得复制报销计算规则。
  - 交易详情支持 Invoice/Receipt 切换查看，并修改分类、均分人数、小费、关联凭证和备注。
  - 模板页展示系统默认模板只读状态，支持复制后修改名称、说明和授权的合规开关。
  - 图片只通过短期预签名 URL 下载到临时缓存；不得长期保存 URL、JWT 或带签名查询参数。
  - 本 Task 不实现导出轮询、ZIP 下载或 Share Sheet。
  - 预估总改动量约 1,650 行（功能 1,200 行、测试 450 行以内），不超过 2,000 行；测试满足项目比例或行数红线。
- **验收标准**：
  - 修改分类、均分人数、小费或备注后，乐观状态能与服务端返回正确对账，失败时回滚并提示。
  - 异常高亮、关联凭证和分组列表使用合成数据完成关键 UI 测试。
  - 默认模板不可直接编辑，自定义副本可保存并在重新加载后保持一致。
