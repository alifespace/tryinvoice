# M4.7-ios-export-and-share：导出轮询、下载预览与系统分享

- **目标**：完成导出闭环：触发导出、轮询任务、下载 ZIP、预览 Excel/文件并通过系统 Share Sheet 分享或保存。
- **前置依赖**：`M3.1-excel-and-zip-exporter`、`M4.6-ios-review-and-templates`。
- **范围与约束**：
  - 调用 `POST /batches/{id}/export`，按有上限的退避策略轮询 `GET /jobs/{job_id}`，处理成功、失败、冲突与超时。
  - 下载短期预签名 URL 到本地临时目录；支持 QuickLook 预览和 `UIActivityViewController` 分享。
  - 分享完成、取消、URL 过期或应用退出后按策略清理临时文件；RawVault 原件不受影响。
  - 模拟器验收使用合成 ZIP；真实微信、邮件、Files 和真机完整链路属于人工门禁。
  - 预估总改动量约 1,050 行（功能 750 行、测试 300 行），不超过 2,000 行；新增测试低于 450 行。
- **验收标准**：
  - 模拟器完成导出触发、状态轮询、ZIP 下载、预览与 Files 分享路径，错误状态均可重试或退出。
  - 临时文件生命周期、过期 URL、轮询取消和重复点击均有确定性测试。
  - 经授权在真机完成“采集 → 自动识别 → 复核 → 导出 ZIP → 分享到 Files/微信”的人工验收。
