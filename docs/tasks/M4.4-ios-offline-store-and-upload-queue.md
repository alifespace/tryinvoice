# M4.4-ios-offline-store-and-upload-queue：SwiftData 离线批次与幂等上传队列

- **目标**：建立 SwiftData 本地模型、只读 RawVault 沙盒、离线批次管理和基于 SHA-256 的后台直传队列。
- **前置依赖**：`M4.3-ios-auth-network-and-account`。
- **范围与约束**：
  - 建立 `LocalBatch`、`LocalDocument` 与上传状态模型，支持离线创建、重启恢复和服务端 ID 回填。
  - 原始文件写入 `Documents/RawVault/{batchId}/` 后不可原位修改；设置备份排除属性并使用原子写入。
  - 上传流程严格调用 presign → 对象存储直传 → confirm，使用 SHA-256 支持秒传和幂等重试。
  - 明确待上传、上传中、已入库、秒传、可重试失败和永久失败状态；应用重启后不得把上传中状态永久卡死。
  - 本 Task 不包含相机、相册、PDF 选择、OCR 或交易复核 UI。
  - 预估总改动量约 1,600 行（功能 1,150 行、测试 450 行以内），不超过 2,000 行；测试满足项目比例或行数红线。
- **验收标准**：
  - 离线创建批次并加入合成文件后，强制重启仍可恢复全部元数据和文件引用。
  - 恢复网络后自动完成幂等上传；重复文件不重复写对象，失败重试不覆盖 RawVault 原件。
  - 上传状态机、哈希、路径安全和恢复逻辑具有纯逻辑测试，关键离线→在线路径通过模拟器测试。
