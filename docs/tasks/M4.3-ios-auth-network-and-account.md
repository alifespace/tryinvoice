# M4.3-ios-auth-network-and-account：Supabase 登录、契约网络层与账号管理

- **目标**：实现 V1 单账号邮箱/密码登录、会话恢复与刷新、OpenAPI 强类型网络层、Bearer JWT 注入和账号删除入口。
- **前置依赖**：`M4.1-test-backend-environment`、`M4.1-fix-deployment-bootstrap`、`M4.1-fix-supabase-jwks-auth`、`M4.2-ios-project-scaffold-and-ci`。
- **范围与约束**：
  - 优先复用官方 Supabase Swift SDK 与 Swift OpenAPI 生成工具链，禁止手写重复的通用认证或 JSON 客户端基础设施。
  - 由 `contracts/openapi.json` 生成或确定性同步 API 类型；实现统一的 base URL、JWT、超时和错误映射。
  - 登录页仅支持已有测试账号邮箱/密码登录，不提供公开注册、找回密码、团队或多账号切换。
  - 会话保存在系统安全存储中；测试账号密码只能通过 GitHub/平台 Secrets 注入，不得进入源码、日志或 Artifact。
  - 实现账号信息与 `DELETE /account` 二次确认入口；Supabase `auth.users` 管理端删除不在本 Task 擅自补写。
  - 预估总改动量约 1,400 行（功能 950 行、测试 450 行以内），不超过 2,000 行；测试满足项目比例或行数红线。
- **验收标准**：
  - 模拟器可登录测试账号，重启恢复会话，并携带 Bearer JWT 调用受保护健康之外的最小 API。
  - Token 失效、网络超时、401 与服务端错误均转换为可恢复状态，不泄露原始 Token 或密码。
  - 账号删除具有明确二次确认并正确处理 204；所有纯逻辑单测与关键登录 UI 测试通过。
